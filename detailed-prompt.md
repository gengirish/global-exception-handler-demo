# Query for LLM to Create Solution for Global Exception Handler Demo

## Task Overview

Create a solution for the Global Exception Handler Demo project, which demonstrates centralized exception handling in a Spring Boot application. The solution should include custom exception classes, a global exception handler using `@ControllerAdvice`, and REST API endpoints that trigger exceptions.

## Key Features to Implement

- Centralized exception handling with `@ControllerAdvice`
- Custom API error response design
- RESTful API best practices
- Comprehensive test suite

## Steps to Complete

3. Develop REST API endpoints that utilize the exception handling.
4. Create a comprehensive test suite to validate the functionality.
